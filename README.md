# Attaques informatiques

Carte mentale réalisée dans le cadre de mon apprentissage en cybersécurité.

Elle présente les principales catégories d’attaques informatiques. Chaque catégorie regroupe plusieurs types d’attaques, et chaque type inclut différents exemples et méthodes d’attaque.

Les catégories abordées sont :
- Attaques contre les utilisateurs
- Attaques contre les données
- Attaques réseau et applicatives
- Attaques contre les systèmes
- Attaques par mots de passe
- Attaques liées à l’intelligence artificielle

- La version PDF permet de consulter la carte mentale directement.
